Receipt String Parsing & Tax Calculator

A beginner-friendly Python mini project focused on string manipulation, data cleaning, extraction, and basic calculations.

The project takes a raw receipt string containing a store name, item, price, and tax rate, then processes the data to extract meaningful information and calculate the final price including tax.

What I Practiced
String methods such as .strip(), .lower(), .title(), .replace(), and .find()
String slicing and .split() for extracting specific values
Converting strings into numeric data using float()
Performing percentage-based calculations
Using f-strings for clean output formatting
Formatting currency values to two decimal places
Writing readable and structured Python code
Example

Input:

STORE: TechMart || item: laptoP || price: $899.99 || tax: 8%


Output:

Store: Techmart
Item: Laptop
Base Price: $899.99
Total (w/ Tax): $971.99

Key Learning

This mini project helped me understand how raw text data can be cleaned, parsed, converted, and transformed into useful information using Python. These are foundational skills that are important for data analysis and data science workflows.
